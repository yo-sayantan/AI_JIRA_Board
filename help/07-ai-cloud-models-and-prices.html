Cloud AI — model prices

What a report costs, per model

The i button beside the cloud model list in Settings opens this table. Rates are USD per 1 million tokens at standard speed. Which models Settings offers — and each one's efforts (Low · Medium · High · Auto) and what counts as costly — is one file, ai-intern/cloud-models.json: add a model there and it appears in Settings, delete it and it is gone, no code change. The prices below are Cursor's published models & pricing table, on file in ai-intern/cursor-prices.json (checked …); it fills in a price that an entry in cloud-models.json leaves out. Edit either file; the worker re-reads it within a minute.

Claude and Gemini — your own keys

Models listed for the direct providers

With Claude (billed by Anthropic, console.anthropic.com) or Gemini (billed by Google, aistudio.google.com) selected in Settings, the dropdown offers these rows of ai-intern/cloud-models.json. Their id must be the exact model id that provider's API accepts. Add the keys with the key button in the board header — they are saved in setup/.env (ANTHROPIC_API_KEY, GEMINI_API_KEY) and used from the next AI call, no restart.

Add or remove a cloud model — cloud-models.json

One file is the whole list

ai-intern/cloud-models.json is exactly what Settings → AI → Cloud offers. Add an entry and the model appears there; delete it and it is gone — no code change, no rebuild. The AI Intern re-reads the file within a minute. Each entry:

{
  "provider": "cursor",            // cursor | claude | gemini
  "name": "GPT-5.6 Luna",          // shown in Settings; for Cursor also how the id is found
  "id": "gpt-5.6-luna",            // exact API id — required for claude and gemini
  "maker": "OpenAI",               // the group in the dropdown
  "outputUsd": 1.2,                // USD per 1M output tokens (omit → cursor-prices.json)
  "efforts": ["low", "medium", "high", "auto"]
}

Costly: a model whose outputUsd is at or above costlyOutputUsd (top of the file — $10 now) gets the ⚠ and, unless costlyShowEffort is true, a fixed Medium effort (the dropdown is shown disabled). One entry can override that with "costly": true or false. Auto leaves the effort to the model and is the default for every other model.
