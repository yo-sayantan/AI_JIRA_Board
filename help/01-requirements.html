Requirements — what to install & where to get it

🐳

Docker Desktop Required

The one-command way to run everything. Builds the app, fetches your tickets, and serves the board.

docker.com/products/docker-desktop
Linux: Docker Engine + Compose

🌿

Git Required

To clone the repo and pull updates.

git-scm.com/downloads

🎟️

Jira Personal Access Token Required

The only credential the board strictly needs. Read scope is enough.

Jira → your avatar → Profile → Personal Access Tokens → Create token. Copy it immediately — you can't view it again.

🟩

Node.js 20+ Optional

Only to build/develop the app outside Docker, or to run the live server.

nodejs.org (LTS)

🐍

Python 3.9+ Optional

Only to run the fetch scripts directly on your machine. The Docker image already contains it.

python.org/downloads

📄

Confluence / Bitbucket tokens Optional

Add richer cards: linked docs, real branch names, PR state and approvals.

Same place as the Jira token, in each product's own settings.

Next: install them — one command per tool on Windows, macOS or Linux.
