Without Docker

📄 Static file — no server

The build is one self-contained HTML file. If a data dump exists, just open it:

# macOS
open dist/index.html
# Linux
xdg-open dist/index.html
# Windows
start dist\index.html

Press r to re-read the latest data.

🖥️ Live local server

The header button becomes a real Refresh that runs the fetch on your machine.

npm install
npm run serve

Serves on port 4321. Needs Node.js 22+.

Develop the app

Build & develop

npm install        # install dependencies
npm run dev        # localhost:5173 — sample data, hot reload
npm run typecheck  # tsc --noEmit
npm run build      # → dist/index.html (single file)

Refresh the data by hand

The fetch scripts

bash jira-intern/local-runner/run-intern.sh        # active tickets (daily)
bash jira-intern/local-runner/update-completed.sh  # full Completed archive (weekly)

Both rewrite jira-intern/data.json and data.js; reload the board to see the result.
